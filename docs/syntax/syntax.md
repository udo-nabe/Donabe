# Donabe 構文の仕様

## 字句
### 整数リテラル
正規表現: `[0-9]+`
### 文字列リテラル
正規表現: `"([^"\n]*)"`
### 真偽値リテラル
正規表現: `true|false`
### 識別子
キーワードに完全にマッチする場合、そちらが優先される。
一部にキーワードを含む文字列(例: **let**ter、**var**iable)は、識別子として認識される。

正規表現: `[a-zA-Z_][a-zA-Z0-9_]*`
### キーワード
- `let`
- `var`
- `if`
- `else`
- `while`
- `for`
- `func`
- `return`
- `in`
- `lazy`
### 記号
文字数の多い記号が優先されてマッチする。
- `==`: EQUAL
- `<=`: LESS_EQUAL
- `>=`: GREATER_EQUAL
- `++`: INCREMENT
- `--`: DECREMENT
- `+=`: PLUS_ASSIGN
- `-=`: MINUS_ASSIGN
- `*=`: ASTERISK_ASSIGN
- `/=`: SLASH_ASSIGN
- `->`: ARROW
- `=`: ASSIGN
- `+`: PLUS
- `-`: MINUS
- `*`: ASTERISK
- `/`: SLASH
- `(`: LPAREN
- `)`: RPAREN
- `{`: LBRACE
- `}`: RBRACE
- `[`: LBRACKET
- `]`: RBRACKET
- `;`: SEMICOLON
- `!`: EXCLAMATION
- `<`: LESS
- `>`: GREATER
- `,`: COMMA
- `:`: COLON
- `.`: DOT
### コメント
#### ラインコメント
`//`で始まるコメント。改行まで継続する。
正規表現: `//[^\n]*(\n|$)`
#### ブロックコメント
`/*`で始まり、`*/`で終わるコメント。複数行をまたぐことができる。ネストは不可。
### 空白文字
トークン間には、いくらでもホワイトスペース(空白文字、タブ文字、改行文字)
を入れることができる。

## プログラム
プログラムは、0個以上の数の文から構成される。
ルートスコープには、任意の文を記述できる。

## 文
文とは、プログラム中に直接記述できる構成要素である。
### ブロック文
`{`を開始、`}`を終了とし、内部に0個以上の文を記述することができる。

例:
```
{
  let block = 100;
}
```

### 空文
`;`だけからなる文である。

### 式文
`式;`という形式の文である。

例:
```
1 + 2;
function();
```

### if文
`if`ブロックは、`if 条件式 ブロック文`という形式の文である。

例:
```
if foo < 10 {
  print("foo < 10");
}
```

`else`ブロックは、`if`ブロックの直後に、
`else ブロック文|if文`という形式で記述する。

例:
```
if foo < 10 {
  print("foo < 10");
} else {
  print("foo >= 10");
}
```
```
if foo < 10 {
  print("foo < 10");
} else if foo < 20 {
  print("foo < 20");
} else {
  print("foo >= 20");
}
```

### while文
`while 条件式 ブロック文`という形式の文である。

例:
```
while foo < 10 {
  print("loop");
}
```

### for文
`for var文 条件式;更新式(;)ブロック文`という形式の文である。
現在では、一般的なCのfor文とは違い、変数の複数宣言と更新式の複数記述は不可。

例:
```
for var i = 0; i < 10; i++ {
  print(i);
}
```
```
for var i = 0; i < 10; i++; {
  print(i);
}
```

### for-each文
`for let`を先頭とする文である。

例:
```
let list = [1, 3, 5, 7, 9, 11];
for let i in list {
  print(i);
}
```

### return文
`return;`または`return 式;`という形式の文である。

例:
```
return;
return "pot";
```

### let文
`let 識別子: 型 = 式;`という形式の文である。

例:
```
let pan: Int = 42;
```

型注釈を省略することもできる。

例:
```
let nabe = 3;
```

### var文
`var 識別子: 型 = 式;`という形式の文である。

例:
```
var pan: Int = 42;
```

型注釈を省略することもできる。

例:
```
var nabe = 3;
```

### 関数定義文
funcキーワードで開始し、各引数の型は通常の型注釈と同じように、
戻り値型は`-> 型`という形式で記述する。

例:
```
func add(a: Int, b: Int) -> Int {
  return a + b;
}
```

### lazy関数定義文
lazyキーワードが先頭に加わった、関数定義文である。

例:
```
lazy func add(a: Int, b: Int) -> Int {
  return a + b;
}
```

## 式
式とは、プログラム中に直接記述することができない、構成要素である。
直接書きたい場合、式文とする必要がある。

### 識別子
`識別子`という形式である。

例:
```
foo
```

### 代入式
`式 = 式`という形式である。右結合である。

例:
```
let pan = 10;
var pot = 0;
pot = pan;
```

### 複合代入式
`式 複合代入演算子 式`という形式である。右結合である。
複合代入演算子には、以下の種類がある。
- `+=`: 加算代入
- `-=`: 減算代入
- `*=`: 乗算代入
- `/=`: 除算代入

例:
```
pot += 3
```

### 二項式
`式 演算子 式`という形式である。左結合である。
以下の種類がある。
- `+`: 加算
- `-`: 減算
- `*`: 乗算
- `/`: 除算
- `==`: 等価
- `>: より大きい
- `<`: 未満
- `<=`: 以下
- `>=`: 以上

例:
```
foo < bar
```

### 単項式
`演算子 式`という形式である。右結合である。
以下の種類がある。
- `-`: マイナス
- `+`: プラス
- `!`: NOT

例:
```
!foo
```

### 真偽値リテラル
`true|false`である。

例:
```
true
```
```
false
```

### 整数リテラル
`整数リテラル`という形式である。

例:
```
42
1234
```

### 文字列リテラル
`文字列リテラル`という形式である。

例:
```
"Donabe"
```

### リストリテラル
`[式リスト]`という形式である。

例:
```
[1, 2, 3]
```
```
["Hello", "Donabe", "World"]
```

### 関数リテラル
`func(引数リスト) -> 戻り値型 ブロック文`という形式である。
引数リストの型注釈は省略できない。

例:
```
func(a: Int, b: Int) -> Int {
  return a + b;
}
```

### 呼び出し式
`式(引数リスト)`という形式である。左結合である。

例:
```
add(1, 2)
```

### インクリメント
後置は`式++`、前置は`++式`という形式である。それぞれ左結合、右結合である。
しかし、連続して記述すると構文エラーとなる。

例:
```
bar++
```
```
++bar
```

### デクリメント
後置は`式--`、前置は`--式`という形式である。それぞれ左結合、右結合である。
しかし、連続して記述すると構文エラーとなる。

例:
```
foo--
```
```
--foo
```

### 添字式
`式[添字]`という形式である。左結合である。

例:
```
list[10]
```
```
[1, 2, 3][1]
```

### メンバアクセス式
`式.識別子`という形式である。左結合である。

例:
```
"Hello".length
```

## 型注釈
### 型名注釈
識別子と同じ形式である。

例:
```
Int
```
```
String
```

### 関数型注釈
`(引数型リスト) -> 戻り値型`という形式である。右結合である。

例:
```
(Int, Int) -> Int
() -> Void
() -> (Int) -> Int
```

### ジェネリック型注釈
`型名注釈<型注釈リスト>`という形式である。

例:
```
List<Int>
List<(Int) -> Int>
List<String>
Map<String, Int>
```
